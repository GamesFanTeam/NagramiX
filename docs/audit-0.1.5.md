# Аудит требований NagramiX 0.1.5

## Реализовано в кандидате 0.1.5

- Файл 1: скрытие нижней панели, вкладки «Контакты» и «Звонки», названия вкладок, кнопка поиска.
- Файл 2: скрытие «Все чаты» при наличии пользовательских папок и восстановление последней папки отдельно для каждого аккаунта.
- Файл 3: компактный список, компактное превью, ID профиля и DC, точная дата создания групп и каналов, подтверждение исходящих звонков.
- Файл 4: скрытие историй, отключение свайпа к камере историй, управление штатным быстрым переводом.
- Файлы 6 и 11: пересылка без автора, пересылка с автором, сохранение в Избранное, сохранение в Файлы и выбор загруженных сообщений автора.
- Файл 5: реальный Force TCP через существующий параметр VoIP и задняя камера по умолчанию для новых круглых видео.
- Файл 9: секунды во времени сообщений.
- Файл 10: скрытие собственного номера в обычных экранах интерфейса и отправка аппаратной клавишей Enter с переносом строки через Shift+Enter.
- Общие требования: отдельный экран «Настройки NagramiX», русская локализация первого запуска, фирменный экран и ровно восемь иконок.

## Уже предоставляет Telegram и переиспользует NagramiX

- Ответ, копирование, закрепление, удаление, жалоба, обычный выбор сообщений и сохранение видео.
- Штатный перевод сообщений и чатов там, где он разрешён Telegram.
- Штатное распознавание голосовых сообщений там, где оно доступно аккаунту.
- Штатный PiP для поддерживаемых типов видео.

## Не включено как фиктивные переключатели

- Файл 2: перенос панели папок вниз и пользовательское название «Все чаты».
- Файл 3: вычисление даты регистрации пользователя по ID.
- Файл 4: внешние сервисы перевода и распознавания, принудительный выбор микрофона.
- Файл 5: изменение качества исходных фото и глобальный размер стикеров.
- Файл 7: глобальная насыщенность персональных цветов.
- Файл 8: новый свайп запуска PiP.
- Файл 9: изменение медиаконвейера, сетевой конкурентности и размера блоков загрузки.
- Файл 10: изменение порядка системной emoji-клавиатуры.
- Файл 11: экспорт логов из контекстного меню без гарантированной полной очистки приватных данных.

Эти функции требуют отдельных Core-задач, компиляционной проверки и тестов на реальном устройстве.

В 0.1.5 для них намеренно не создаются переключатели, которые ничего не делают.
