# NagramiX 0.1.3 — тестовая unsigned-сборка

## Что добавлено

- Экран «Настройки NagramiX» расположен выше пунктов «Избранное» и «Недавние звонки».
- По умолчанию нижняя панель содержит Чаты и Настройки.
- Поиск отображается отдельной системной кнопкой.
- Контакты и Звонки возвращаются отдельными переключателями.
- В приложении доступны ровно 8 фирменных иконок NagramiX.
- Иконка «Закат» использует обновлённый вариант изображения.
- Время сообщений может отображаться с секундами.
- Перед голосовым или видеозвонком можно включить подтверждение.
- Собственный номер телефона можно скрыть локально в интерфейсе.
- В профиле можно показывать ID и доступный DC ресурса аватара.
- Для круглых видеосообщений задняя камера выбрана по умолчанию.
- Добавлены компактный список чатов и компактный предпросмотр сообщений.
- Автопереключение прокси поддерживает интервалы 15, 30 и 60 секунд.
- Меню Debug переведено на русский язык.

## Контекстное меню сообщения

Действия отображаются только там, где они разрешены типом сообщения и правами пользователя.

- Ответить.
- Скопировать.
- Закрепить.
- Переслать — без имени исходного автора.
- Переслать от — с указанием исходного автора.
- Сохранить в Избранное.
- Сохранить в Файлы.
- Выбрать.
- Выбрать от — выделяет загруженные сообщения этого автора.
- Удалить.
- Пожаловаться.

## Файл для установки

`NagramiX-0.1.3-unsigned.ipa`

IPA не подписан сертификатом Apple.

Перед установкой его необходимо подписать через SideStore или другой совместимый сервис.
