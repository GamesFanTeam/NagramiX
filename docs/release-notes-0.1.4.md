# NagramiX 0.1.4 — тестовая unsigned-сборка

## Что изменено

- Канал «Спонсор Прокси» скрыт по умолчанию.
- В разделе «Настройки NagramiX» → «Инструменты» добавлен переключатель «Показывать Спонсор Прокси».
- Изменение применяется сразу к открытому списку чатов.
- Обычные каналы пользователя и другие системные сообщения Telegram не скрываются.
- Сохранены все функции версии 0.1.3.

## Файл для установки

`NagramiX-0.1.4-unsigned.ipa`

IPA не подписан сертификатом Apple.

Перед установкой его необходимо подписать через SideStore или другой совместимый сервис.
