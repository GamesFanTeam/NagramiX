# NagramiX 0.1.5 — тестовая unsigned-сборка

Версия 0.1.5 расширяет самостоятельный раздел «Настройки NagramiX».

Добавлено управление видимостью нижней панели, названиями вкладок и кнопкой поиска.

Добавлено скрытие историй и отключение свайпа для открытия камеры историй.

Добавлено управление быстрым переводом сообщений.

Добавлено скрытие раздела «Все чаты» при наличии пользовательских папок.

Добавлено восстановление последней открытой папки отдельно для каждого аккаунта.

Добавлена отправка сообщения аппаратной клавишей Enter.

Комбинация Shift+Enter сохраняет перенос строки.

Добавлен Force TCP для звонков через существующую конфигурацию Telegram VoIP.

Добавлена точная дата создания групп и каналов, когда это значение предоставляет Telegram Core.

Добавлены отдельные переключатели дополнительных действий контекстного меню: пересылка без автора, пересылка с автором, сохранение в Избранное, сохранение в Файлы и выбор сообщений автора.

Сохранены настройки компактного списка, секунд, подтверждения звонков, приватности интерфейса и автопереключения прокси.

Запись нового круглого видео по умолчанию начинается с задней камеры.

Ручное переключение камеры во время записи остаётся доступным.

Первый запуск переведён на русский язык и использует фирменный экран NagramiX.

В набор приложения входят ровно восемь обновлённых иконок NagramiX.

Файл сборки должен называться:

`NagramiX-0.1.5-unsigned.ipa`

IPA не содержит Apple-сертификатов и требует последующей подписи выбранным пользователем способом.
