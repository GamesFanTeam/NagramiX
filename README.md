# NagramiX

**NagramiX** — независимый неофициальный клиент Telegram для iOS.

Проект использует [Telegram-iOS](https://github.com/TelegramMessenger/Telegram-iOS) как кодовую базу.

Функции NagramX переносятся как нативные возможности iOS, без компиляции Android-кода.

## Текущая версия: 0.1.3

- База: Telegram-iOS 12.9.2, закреплённая в `nagramix/upstream.env`.
- Ориентир функций: NagramX tag `1258` / 12.9.2.
- Bundle ID: `com.gamesfanteam.nagramix`.
- В наборе ровно 8 фирменных иконок NagramiX.
- По умолчанию в нижней панели отображаются Чаты, Настройки и отдельная кнопка Поиска.
- Контакты и Звонки можно вернуть через Настройки NagramiX.
- Добавлены переключатели интерфейса, профиля, звонков и камеры.
- Добавлены два режима пересылки и расширенные действия контекстного меню сообщений.
- Автопереключение прокси поддерживает интервалы 15, 30 и 60 секунд.
- Результат сборки: `NagramiX-0.1.3-unsigned.ipa` без Apple-подписи.

GitHub Actions применяет изолированный overlay NagramiX к закреплённой ревизии upstream.

Сборка выполняется для ARM64 на macOS runner.

Сертификаты Apple и секреты подписи в репозитории не хранятся.

Для сборки используются секреты `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`, полученные на <https://my.telegram.org/apps>.

Подробное описание версии находится в [заметках к выпуску 0.1.3](docs/release-notes-0.1.3.md).

План, риски и чек-лист проверки через SideStore находятся в [docs/BOOTSTRAP.md](docs/BOOTSTRAP.md).
